# AI Chatbot using Python

A beginner-level AI chatbot developed using Python, implementing rule-based conversational logic and regex-based intent recognition for interactive user communication.

---

##  Features

- Greeting responses
- Date and time support
- Help assistance
- Rule-based intent matching
- Interactive conversation handling

---

## Technologies Used

- Python
- Regular Expressions (Regex)
- Datetime Module

---

##  Project Type

Rule-Based AI Chatbot

---

##  Run the Project

```bash
python chatbot.py
```
